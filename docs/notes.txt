% --- PARAGRAPH 4: The evaluation problem --- signer-disjoint ---
% - Standard practice in prior PSL work = random train/test split
%   → This allows same signer's videos in both train AND test
%   → Model can learn: "this background = class X" or "this hand size = signer Y = class Z"
Signer-Independent (SI) vs. Signer-Dependent (SD): While SD models (same signers in training/test) show higher accuracy, SI models (disjoint sets) are essential for real-world, inclusive applications.Generalization Goal: By forcing the model to learn the underlying movement patterns rather than the specific, unique appearance of a specific person's hands or clothes, the model becomes more robust.
%   → Called signer leakage / signer-inclusive evaluation
%   → Accuracy looks high but tells you nothing about real-world use
% - We introduce: strictly signer-disjoint evaluation
%   → No signer (and no augmented variant of their video) appears in more than one split
%   → Reflects real deployment: model will always encounter NEW signers
%   → This is the LOSO (Leave-One-Signer-Out) standard recommended in literature
%   → Prior PSL work has not adopted this — our paper is first to enforce it for PSL. and we show it on PSL-104

% --- PARAGRAPH 5: Why scratch CNN architectures fail under signer-disjoint ---
% - We first evaluate 3D-CNN + Residual Blocks + BiLSTM (similar class to Hamza 2023's C3D/I3D/TSM)
% - Under signer-disjoint: 2.88% accuracy (random chance = 0.96% for 104 classes)
% - Consistent with Marc et al. (2023) findings on LSA64, Hamza & Wali (2023) on PSL
%   → These models work fine signer-inclusively (83.89% in our own prior FYP work)
%   → But collapse completely when signer identity is removed from the equation
% - Root cause: ~15 clips/class is 40x below minimum viable training for 3D-CNNs
%   → Model has no visual prior → must learn "what hands look like" from 15 examples
%   → This is impossible; the model memorizes signer identity instead
% - Also: static sign methods (Imran 2021, Arooj 2024) have the same fundamental
%   limitation of not modelling dynamics at all

% --- PARAGRAPH 6: SignVLM as the solution ---
% - Pretrained large video model: CLIP ViT-L/14 (frozen) + EVL temporal decoder (trainable)
% - CLIP pretrained on 400M image-text pairs → already knows what hands look like
%   → No need to learn visual priors from PSL data → no data bottleneck
% - EVL decoder: lightweight temporal transformer → learns PSL-specific motion from limited data
% - Only temporal decoder trained on PSL; backbone frozen → parameter-efficient
% - Results (signer-disjoint, 24 frames/clip):
%   → Val: 83.49%, Test: 83.12% (with augmentation)
%   → Val: 85.14%, Test: 84.21% (original only, full-shot)
% - N-shot: 4-shot → 81.25% val; 8-shot → 84.29% val
%   → Even with 4 videos/class, model achieves practical accuracy
%   → Huge practical implication: don't need large dataset to deploy
